# OpenPEMF

An open-source medical device to stimulate blood-flow and potentially relieve pain in targeted areas.

> [!WARNING]
> OpenPEMF creates rapidly changing electromagnetic fields and can cause **serious death or injury** if used incorrectly. OpenPEMF is an **untested**, **non-FDA evaluated**, **Pulsed Electromagnetic Field (PEMF) device**, and should **NOT** be used by you or others with in-body electronics such as pacemakers, hearing aids, or any other **magnetic-sensitive implants**.

## About

The OpenPEMF project was created as an open-source design inspired by the [BEMER device](https://bemergroup.com/en_US/human-line/products/overview), built for a cost significantly cheaper than the ~$4k (USD) BEMER. The BEMER device specifically uses Pulsed Electromagnetic Fields (PEMF) to, what the BEMER Group has claimed, stimulate blood flow in parts of the body.

Whilst the effects of PEMF therapy are unstudied and controversial, there is a chance that PEMF devices **do** stimulate blood movement to some degree. OpenPEMF was designed to be affordable and easy to build, so the potential of users spending several thousands on a placebo no longer exists.
